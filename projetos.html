Projeto acadêmico · Desenvolvimento de Software Multiplataforma

Negado pelo Banco

Problema: explorar formas de apoiar uma análise de crédito mais inclusiva a partir de dados públicos e informações relevantes para a tomada de decisão.

Solução: desenvolvimento colaborativo de uma aplicação acadêmica que utiliza dados do Banco Central do Brasil como base para estudar o problema.

Tecnologias: Python, APIs e ferramentas de desenvolvimento colaborativo. A lista deve ser ajustada conforme as tecnologias efetivamente utilizadas na versão final.

Minha contribuição: participação no desenvolvimento e na integração das partes do projeto com a equipe, incluindo o trabalho de organização e teste dos scripts.

Projeto pessoal · Desenvolvimento web

SLY Company

Objetivo: criar a presença digital de uma marca independente de streetwear, apresentando sua identidade e seus produtos.

Solução: site com páginas de início, sobre a marca, catálogo de produtos e contato, com atenção à tipografia, composição visual e navegação.

Tecnologias: HTML, CSS, Bootstrap e JavaScript.

Aprendizados: estruturação de páginas, criação de layouts, estilização, navegação entre páginas e organização de arquivos front-end.
